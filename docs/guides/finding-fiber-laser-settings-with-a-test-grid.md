# Finding fiber laser settings with a test grid

**Short answer:** settings tables are only a starting point. Your laser source, lens, focus and the alloy
in front of you all shift the result. The fastest way to find your own settings is one coupon that marks
many combinations side by side and engraves each value beside its square.

## Why borrowed settings miss

The same "stainless steel" setting can come out very differently on another machine. Lens focal length,
focus height, source wattage, pulse width and the alloy itself all change how much heat lands on the
surface. Treat any published setting as the middle of your first sweep, not the answer.

## Start simple, then build up

1. **One layer, two settings.** Add a Test Grid (**Add Action › Calibration › Test Grid**), put one setting on
   X and one on Y (say power across, speed up), and mark it. The labels can include the detailed values —
   everything you need to recreate the mark.
2. **Go further.** The same grid can sweep a fill variation range, try a different fill pattern, or stack
   layers with different combinations in every square. Each step builds on the last.

Found the one? Right-click the square › **Open in Library** › **Save as Template…**. Every setting is
saved, ready to recall for real work — no library management beyond a template name.

!!! tip "Focus first"
    A grid marked out of focus tells you little. Find the focal height with the
    [Z Focal Distance test](../lenses-corrections.md#finding-focus-the-z-focal-distance-test) before you sweep.
